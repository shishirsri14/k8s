# Kubernetes Practice & Deployment

This repository contains my hands-on practice with Kubernetes, including cluster creation, deployments, services, ingress, namespaces, persistent storage, and application deployment.

The main goal of this repository is to understand how containerized applications are deployed, exposed, and managed inside a Kubernetes cluster.

---

## 🚀 What I Practiced

- Kubernetes cluster creation using Kind
- Multi-node Kubernetes cluster
- Namespaces
- Deployments
- Pods
- Services
- ConfigMaps and Secrets
- NGINX deployment
- REST API deployment
- Ingress configuration
- MySQL deployment using StatefulSet
- Persistent storage
- Service-to-service communication
- Kubernetes YAML manifests
- Scaling and replica management
- Basic troubleshooting using `kubectl`
